Política de Privacidade

KAIZO

Última atualização: 22 de Outubro de 2025

Na Kaizo, levamos a sua privacidade a sério. Esta Política de Privacidade tem o objetivo de explicar, com total transparência, como coletamos, usamos, armazenamos e protegemos os seus dados pessoais durante a sua interação com o nosso site e com a plataforma Kaizo LabLauncher.

Ao utilizar nossos serviços, você concorda com os termos descritos a seguir.

Base Legal

Esta Política de Privacidade está em conformidade com a Lei Geral de Proteção de Dados (LGPD) – Lei nº 13.709/2018, garantindo os direitos e deveres relacionados à coleta, uso e proteção de dados pessoais.

1. Coleta e Uso de Informações

Coletamos vários tipos diferentes de informações para diversos fins, a fim de fornecer e melhorar nosso Serviço para você.

  • Dados Pessoais: Ao usar nosso Serviço, podemos solicitar que você nos forneça certas informações de identificação pessoal que podem ser usadas para contatá-lo ou identificá-lo ("Dados Pessoais"). Isso pode incluir, mas não se limita a: endereço de e-mail, nome e sobrenome, dados de currículo.
  • Dados de Uso: Também podemos coletar informações sobre como o Serviço é acessado e usado ("Dados de Uso").

2. Uso dos Dados

KAIZO usa os dados coletados para vários propósitos:

  • Para fornecer e manter nosso Serviço;
  • Para notificá-lo sobre alterações em nosso Serviço;
  • Para permitir que você participe de recursos interativos do nosso Serviço quando optar por fazê-lo;
  • Para monitorar o uso do nosso Serviço;
  • Para detectar, prevenir e resolver problemas técnicos.

Importante: A Kaizo NÃO vende, NÃO aluga e NÃO compartilha seus dados com terceiros para fins de marketing.

3. Segurança dos Dados

A segurança dos seus dados é importante para nós, mas lembre-se de que nenhum método de transmissão pela Internet ou método de armazenamento eletrônico é 100% seguro. Embora nos esforcemos para usar meios comercialmente aceitáveis para proteger seus Dados Pessoais, não podemos garantir sua segurança absoluta.

4. Compartilhamento de dados com terceiros

Para garantir a operação e a segurança da plataforma, alguns serviços de infraestrutura são fornecidos por parceiros tecnológicos de confiança:

Render: Responsável pela hospedagem do site e do banco de dados

Amazon Web Services (AWS): Utilizada para armazenamento seguro de arquivos e dados (ex.: uploads de usuários, modelos 3D, etc.)

O compartilhamento com esses parceiros é feito exclusivamente para garantir o funcionamento técnico da plataforma, sob contratos que exigem o mesmo nível de proteção de dados determinado pela LGPD.
